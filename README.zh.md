# Windows SMS Bridge · 短信桥

[English](README.md) | **简体中文** | [日本語](README.ja.md)

[android-agent-sms-bridge](https://github.com/tiny-andr/android-agent-sms-bridge) 的 Windows 桌面客户端：把手机里已有的短信变成电脑上可浏览、可搜索、可自动同步的本地资料，不经过任何云端。

```
┌────────────────┐   HTTPS + HMAC-SHA256   ┌──────────────────────┐
│   手机 App     │ ◀─────────────────────▶ │  Windows SMS Bridge  │
│   短信桥       │      同一 WiFi / 隧道    │  本程序               │
└────────────────┘                         └──────────────────────┘
```

## 配对手机

1. 手机打开 **短信桥** → **启用服务** → 记下首页显示的地址，例如 `https://192.168.1.100:8787`
2. 手机进入 **配对** 页面，拿到 6 位配对码（**5 分钟有效、一次性**）
3. 电脑点右上角 **配对手机** → 填地址和配对码 → **配对并同步**
4. 把弹窗里的证书指纹与手机配对页上那一行对一下

首次连接会把手机的自签名证书固定下来（TOFU），之后每个请求都用这张证书校验，正文全程加密。

可以配对多台手机：每台一枚独立密钥，在顶部设备栏各占一个卡片，随时可在手机的配对列表里吊销。

> 手机 App 升级会换新证书，旧密钥随之失效：右键该设备 → **重新配对（换新密钥/证书）**，已缓存的短信不会丢。

## 功能

| | |
|---|---|
| 多手机 | 每台独立密钥，显示电量、运营商、最近同步时间 |
| 手动同步 | 设备栏 **同步** 按钮（`Ctrl+R`），同步当前设备或全部设备 |
| 定时同步 | 关闭 / 1 / 5 / 15 / 30 / 60 分钟，后台静默执行 |
| 开机自启 | 单条 `Run` 注册表项，可选登录后静默驻留托盘 |
| 托盘常驻 | 关窗即收进托盘；托盘菜单可同步、退出 |
| 视图 | 全部短信 / 收件箱 / 已发送 / 未读，按设备或全部设备筛选 |
| 会话视图 | 按号码聚合、未读计数、日期分隔、收发气泡区分 |
| 搜索 | 号码或正文模糊搜索（`Ctrl+K`） |
| 导出 | 单个会话或全部导出 CSV（UTF-8 BOM，Excel 直接打开） |
| 主题 | 深色玻璃 / 米白纸感，标题栏一键切换 |
| 界面缩放 | 85 %–150 %，文字与间距一起缩放 |
| 语言 | English / 简体中文 / 日本語，默认跟随系统 |
| 只读 | 不向手机写入任何内容：不发短信、不改已读状态 |

## 同步策略

- **首次同步**（配对完成后）：`GET /v1/sms?days=30&box=all&limit=200`，按 offset 分页读最近 30 天。
- **日常同步**：`GET /v1/sms?since_id=<本地最大 id>&box=all`，只取新消息。
- 按手机端的 `_id` 去重；正文或已读状态变化时原地更新本地副本。
- 每台手机同时只跑一个同步任务。手机端限流 60 次/分钟，一次日常同步通常只有 1 个请求。

手机端会把 `days` 钳到 30、`limit` 钳到 200；要读更早的历史得在手机上放宽上限。

## 数据

全部数据都在本机 `%APPDATA%\Windows SMS Bridge\`：

- `config.json` — 已配对设备与偏好设置；配对 token 用 Windows DPAPI 加密
- `messages.json` — 本地短信缓存（明文 JSON，介意的话用 BitLocker 保护整盘）

程序只读：不向手机写入、不发短信、不把手机上的短信标为已读。

## 安全模型

- **传输层是 TLS。** 手机用自签证书提供 HTTPS，首次配对时抓取并固定该证书（TOFU），之后每次请求严格校验 —— 同一 Wi-Fi 下抓包也读不到短信正文和配对 token。
- **TLS 之上还有签名。** 每个请求带 `X-Client-Id`、`X-Timestamp`、`X-Nonce` 和对「方法 + 路径 + 原始 query + 时间戳 + nonce」的 HMAC-SHA256 签名，兼顾防篡改与防重放（±5 分钟窗口、nonce 一次性）。
- **已知局限。** 手机私钥打包在 APK 内，所以这层 TLS 挡得住被动嗅探，挡不住能反编译 APK 拿到私钥的人；真正的身份保证仍来自 token —— 没有它签不出请求。
- **令牌落盘。** 用 Windows DPAPI 加密，只有当前 Windows 账户能解。
- **远程访问。** 走 Tailscale / WireGuard，不要把 8787 端口映射到公网。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 连接被拒绝 | 手机上的服务没启动 | 在手机 App 里「启用服务」 |
| 超时 | 锁屏后厂商 ROM 冻结了 App | 允许后台运行、关闭省电模式后重试 |
| 「证书未受信任」 | 证书变了（重装过 App）或从未配对 | 重新配对 |
| 设备卡片显示「需重新配对」 | 密钥在手机上被吊销 | 右键 → **重新配对** |
| 收件箱为空 | 最近 30 天没有短信，或未授予 `READ_SMS` | 检查手机权限与回溯天数 |
